# Additional model illustrations (0.3.1)

The Convergence and Cinders atlases were created with the built-in image generation tool, using the approved original mascot atlas as a style reference. They are original simplified illustrations, not extracted game textures or in-game screenshots.

Appearance references were inspected directly from the installed Convergence 2.2.1 and Cinders 2.15 FLVER model geometry, with the corresponding NPC display masks. These bind-pose references establish silhouettes and equipment; they do not establish exact in-game lighting, colors or animation. Shapes and colors are deliberately softened for a non-frightening selector.

- Convergence: `assets/mascots_convergence.png`, four columns and seven rows, 27 model illustrations and one unused symbol.
- Cinders: `assets/mascots_cinders.png`, four columns and six rows, 18 model illustrations, three invisible helper symbols and three unused symbols.
- `assets/mod-art.json` maps model IDs to zero-based, row-major atlas positions.
- `assets/mod-art-prompts.json` records the generation prompts.

No installed mod model, texture, mesh inspection render or private diagnostic is distributed. Model IDs without an authoritative name remain labeled with their ID. Existing species continue to use the original mascot atlas; a mod can alter those species' appearances.

Reference indexes: [DS3 Convergence enemies](https://the-convergence-mod.wikidot.com/enemies), [Cinders enemies](https://ds3-cinders.wikidot.com/enemies), [Cinders source](https://github.com/vawser/Cinders-DS3).

새 그림은 실제 모델의 형태·장비를 확인한 뒤 귀엽게 단순화했습니다. 정확한 인게임 색감이나 자세를 재현한 그림은 아닙니다. 모습이 없는 보조 개체에는 임의의 몬스터 외형을 붙이지 않고 기호를 사용했습니다.
