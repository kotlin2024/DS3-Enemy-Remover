# DS3 Enemy Trainer 0.3.4

개발자 HJP. 하나의 EXE에서 바닐라·컨버전스·신더 탭을 선택할 수 있습니다.

## 사용 방법

1. 이전 트레이너를 종료하고 DS3-Enemy-Trainer.exe를 실행하세요.
2. 게임을 오프라인으로 실행하고 캐릭터를 불러오세요.
3. 실행한 게임에 맞는 탭을 선택하세요. 탭 선택은 게임에 설치된 모드를 변경하지 않습니다.
4. 제거할 몬스터를 선택하세요. 현재 로드된 종류 필터로 게임에 불러온 종류를 볼 수 있고, 모델 번호로도 검색할 수 있습니다.
5. 오프라인 확인과 몹 제거 사용을 체크한 뒤 몹 제거 시작을 누르세요. 모드 주의사항이 나오면 확인하세요.
6. 실행 중 몬스터를 추가로 선택하면 바로 반영됩니다. 시작을 다시 누를 필요가 없습니다.
7. 게임 탭이나 제거 방식을 바꾸면 제거가 멈추고 복원을 시도합니다. 선택을 확인한 뒤 시작을 다시 누르세요.

**이 프로그램을 켜 두고 제거를 실행하는 동안에만 적용됩니다. 종료하면 몹 비활성화가 해제됩니다.** 바로 돌아오지 않으면 지역을 다시 불러오세요. 최소화하면 계속 실행됩니다.

탭별 선택 목록을 따로 기억합니다. 언어·탭·제거 방식도 저장됩니다. 프로그램을 다시 실행하면 오프라인 확인과 몹 제거 사용을 체크하고 시작을 눌러야 합니다.

## 모드별 목록

- 바닐라: 기본 게임의 몬스터와 배치 목록.
- 컨버전스: 로컬 설치 데이터 16개 맵, 3,242개 배치, 추가 모델 27종.
- 신더: 로컬 설치 데이터 20개 맵, 3,827개 배치, 추가 모델 21종.
- 확인된 보스·NPC와 보스 체력바/처치 이벤트 개체는 제외합니다. 모드에서 추가된 보스도 확인된 항목은 제외합니다.
- 기존 몬스터는 원본 모델 이름을 사용합니다. 모드가 이름·외형을 바꾸면 실제와 다를 수 있습니다. 신더 배치에 작성된 이름은 원문을 사용하며, 확인하지 못한 추가 몬스터는 모델 번호로 표시합니다. 추가 모델 48개에 전용 그림을 연결했습니다. 설치된 모델에서 확인한 외형을 귀엽게 단순화했으며, 모습이 없는 보조 개체 3개는 기호로 표시합니다.
- 맵별 목록은 각 모드의 배치 데이터를 사용합니다. 지역 이름은 기본 맵의 지리적 이름이므로 모드가 바꾼 이름과 다를 수 있습니다. 로드된 개체에는 화면 밖의 몬스터도 포함됩니다.

실행 중인 로더와 설정에서 게임 종류를 확인할 수 있으면 감지 결과를 표시합니다. 탭과 다르면 제거를 멈춥니다. 다른 로더나 압축 해제 설치에서는 감지가 어려울 수 있으므로 직접 맞는 탭을 선택하세요.

## 제거 방식

Mod Engine 2로 실행한 경우에도 감지합니다. 실행 중인 게임의 로더와 실행에 사용된 TOML 설정에서 활성화된 신더·컨버전스를 확인합니다. 감지할 수 없는 환경은 수동으로 탭을 선택할 수 있습니다. 감지된 게임과 탭이 다르면 잘못된 보호 기준을 사용하지 않도록 제거를 멈춥니다. 감지가 게임 파일을 변경하거나 모드를 설치하는 것은 아닙니다.

- 종류 전체 제거: 같은 모델 번호를 모든 지역에서 처리합니다. 위치가 바뀌거나 수가 늘어난 경우에도 적용합니다. 확인된 보스·NPC는 제외합니다.
- 확인된 배치만 제거: 현재 탭의 등록된 맵·모델·배치 번호와 일치하는 개체만 처리합니다. 바닐라 또는 범위를 좁혀 사용하고 싶을 때 적합합니다. 다른 버전에서 추가·변경된 개체는 남을 수 있습니다.

현재 모드 목록은 개발에 사용한 로컬 설치본(컨버전스 2.2.1 / 신더 2.15 데이터)을 기준으로 합니다. 다른 버전이나 추가 수정에서 등장한 보스·NPC·모델은 확인되지 않았을 수 있습니다. 종류 전체 제거에서 선택한 모델이 새 보스·NPC로 재사용되면 진행에 영향을 줄 수 있으므로 안내를 확인하세요.

2026-10-10 사용자가 바닐라 몹 제거와 컨버전스·신더의 몹 제거 및 소울 소지량 설정이 게임에서 정상 작동한다고 확인했습니다. 자동 검사 51개와 전용 창 검증도 통과했습니다. 이는 테스트한 로컬 설치 환경에서의 확인이며 모든 버전·지역·추가 모드에 대한 호환성을 보장하지 않습니다.

## 설치 및 업데이트

Windows, 지원하는 DS3 1.15.0.0 실행 파일, Microsoft Edge WebView2 Runtime, .NET Framework 4.6.2 이상이 필요합니다. EXE 실행에 Python은 필요하지 않습니다. WebView2: https://developer.microsoft.com/microsoft-edge/webview2/

기존 selection.json과 settings.json을 새 EXE 옆으로 복사하면 설정을 유지합니다. 이전의 단일 선택 목록은 바닐라 탭으로 옮겨집니다. 게임 파일·세이브·HP·이벤트 플래그를 직접 수정하거나 게임에 코드를 주입하지 않습니다. 오프라인 체크는 사용자의 확인이며 자동 판정이 아닙니다.

로딩 중에는 처리를 멈추고 게임 상태가 안정된 뒤 재개합니다. 제거 완료는 현재 불러온 대상의 비활성화 플래그를 확인했다는 뜻입니다. 이후 나타나는 대상도 계속 처리합니다. 즉시 사라짐·충돌 제거·복원 시점은 개체에 따라 다를 수 있습니다.

소스 빌드 방법은 README_EN.md를 참고하세요. 배포에는 게임 모델·텍스처·맵·파라미터·메시지·이벤트 원본 파일이 포함되지 않습니다.


## 소울 설정

오른쪽 몹 제거 영역 아래에서 현재 소울을 확인하고 변경할 소지량(0~999,999,999)을 입력하세요. 소울 카드의 오프라인 확인을 체크한 뒤 소울 적용을 누르면 한 번만 소지량을 설정합니다. 몹 제거 시작이나 몹 제거 사용 체크는 필요하지 않습니다. 로딩 중·타이틀·게임 미연결·탭 불일치에서는 적용할 수 없습니다. 추가 지급이나 소지량 고정 기능이 아니며, 소울레벨·누적 획득 소울·회수할 소울은 변경하지 않습니다. 게임이 저장하면 프로그램 종료 후에도 변경한 소지량이 유지됩니다. 프로그램은 세이브 파일을 직접 편집하거나 강제로 저장하지 않습니다.
